Performance Evaluation of Distributed Log Processing Using Apache Spark

Project Overview
This research project evaluates the performance of Apache Spark for processing large-scale web server log data and compares it with sequential Python processing.

Dataset
The project uses Apache web server access log data with different dataset sizes:
10,000 records
100,000 records
500,000 records
1 million records
5 million records

Operations Performed
The experiments include:
Counting HTTP status codes
Counting 4xx and 5xx errors
Counting URL requests
Log data aggregation

Performance Metrics
The following metrics are used to compare Python and Apache Spark:
Execution Time
Throughput
Speedup
Scalability

Technologies Used
Python
Apache Spark / PySpark
Jupyter Notebook
Java JDK 17
CSV log datasets
